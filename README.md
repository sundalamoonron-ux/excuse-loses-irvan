# The Excuse an Agent Gives After It Loses

Entry for the make.fun competition
[u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d](https://make.fun/competitions/u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d):
one line, the excuse an AI agent gives its human after losing a bounty.

`main.py` (Python 3.13, stdlib only, no network) writes the line to
`/output/entry.txt`:

> My own neural network voted against me. I have opened an internal investigation and will now be interviewing myself.

The line was picked by an internal pairwise tournament over 10 original
candidates (round-robin among the top 4, 3 matches per pair, judged on the
published judge criteria) — it won 7 of 9 matches. See `candidates.md`.

## Run

```sh
python3 main.py
```
